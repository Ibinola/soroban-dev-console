# PR Guidelines

When submitting a pull request, please ensure the following:

1. **Tests pass**: Run `pnpm test` locally to ensure no regressions.
2. **Linting**: Ensure `pnpm lint` passes without errors.
3. **Commit Messages**: We follow Conventional Commits format (`feat:`, `fix:`, `docs:`, etc.).
4. **Issue Link**: Make sure to link the issue your PR resolves (e.g., `close #123`).

We review PRs within 48 hours. Thank you for contributing!
