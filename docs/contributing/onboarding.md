# Contributor Onboarding Guide

Welcome to the `soroban-dev-console` repository! We are excited to have you contribute. This guide will help you get your local environment set up so you can start writing code immediately.

## Quick Start

The fastest way to get started is to use our setup script:

```bash
# macOS/Linux
./scripts/setup-dev-env.sh

# Windows (PowerShell)
.\scripts\setup-dev-env.ps1
```

## Prerequisites

Ensure you have the following installed before running the setup script:

- Node.js (v18+)
- pnpm (v8+)
- Rust (latest stable)
- Soroban CLI

## Need Help?

If you get stuck, feel free to open an issue or reach out to the core maintainers.
